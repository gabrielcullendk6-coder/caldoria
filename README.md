# Eco das Cavernas

RPG idle no navegador, inspirado no Tibia. Jogue em: `https://SEU-USUARIO.github.io/eco-das-cavernas/`

Sprites: OpenTibia Sprite Pack (CC BY 4.0).

## Como publicar no GitHub Pages
1. Crie um repositório público chamado `eco-das-cavernas`.
2. Envie `index.html`, `.nojekyll` e este README (Add file → Upload files).
3. Settings → Pages → Source: "Deploy from a branch", branch `main`, pasta `/ (root)` → Save.
4. Em 1–2 minutos o jogo abre no link acima.

O save fica no navegador. Para levar o personagem entre aparelhos use Configurações → Exportar/Importar save.
